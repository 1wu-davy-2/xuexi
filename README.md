# 成考冲刺 · 江苏专升本（理工类）复习系统

为 **江苏省成人高考专升本（理工类）** 定制的零基础冲刺复习应用。

- **科目**：政治 · 英语 · 高等数学（一），各 150 分，总分 450
- **目标**：150~180 分稳妥过线（江苏省控线近年约 100~120，年满 25 周岁投档再加 20 分）
- **考试**：2026 年 10 月 17–18 日（全国统考），第一天上午政治、下午英语，第二天上午高数（一）
- **依据**：《全国各类成人高等学校招生考试大纲（2024 年版）》；题库含 2017–2025 年历年真题（转写自公开资料、逐题验算）与原创配套题

## 快速开始

```bash
cd E:\tmp\Zcode\xuexi
npm install        # 首次已安装可跳过
npm run dev        # 启动后访问 http://localhost:18888
```

- 开发服务器端口固定为 **18888**（`vite.config.ts` 中 `strictPort`），避免与本机其他项目冲突。
- 手机访问：同一局域网下打开终端里显示的 Network 地址（如 `http://192.168.x.x:18888`）。
- 生产构建：`npm run build`（产物在 `dist/`），本地预览构建结果：`npm run preview`。
- 自动化验收：`npm run test:e2e`（无头 Chrome 端到端，29 项断言）、`npm run test:data`（题库静态校验）。

## 登录与云同步

系统支持**账号登录 + 云端进度同步**（登录后学习进度自动保存到服务器 SQLite，换设备/多设备不丢）：

- 默认账号：**admin / admin@123**（首次启动自动创建；密码可在首次部署前用环境变量 `ADMIN_PASSWORD` 覆盖）
- 登录后所有进度（已学课件、刷题记录、模考成绩、错题本、计划勾选）自动同步，改动后约 1 秒推送到服务器
- **本地模式降级**：服务器不可达时应用自动进入本地模式（进度仅存本浏览器），恢复后可在「设置 → 重试连接」回到云同步；登录页也提供「本地模式进入」入口
- 会话有效期 7 天（`SESSION_DAYS` 可调），登录接口有基础限速防爆破

## Docker Compose 部署（推荐）

```bash
cd xuexi
docker compose up -d --build     # 构建并启动，访问 http://localhost:18888
```

- **数据持久化**：SQLite 数据库挂载在宿主机 `./data/app.db`（volume `./data:/app/data`），重建/升级容器、更换镜像数据都不丢；备份即复制这一个文件（含 `-wal/-shm` 时先停容器或用 `sqlite3 .backup`）
- 端口：默认映射 **18888**，在 `docker-compose.yml` 的 `ports` 里改
- 首次启动自动建库并创建默认账号；`ADMIN_PASSWORD` 环境变量仅在**首次初始化（data 目录为空）时生效**
- 镜像特点：多阶段构建，运行层**零 npm 依赖**（后端只用 Node 内置模块，SQLite 用 Node 22 内置 `node:sqlite`），运行镜像不含 node_modules

本地以生产模式跑（不开 Docker）：

```bash
npm run build
npm run start        # 即 node server/server.mjs，默认 3000 端口，数据在 ./data
```

开发模式（前后端分离调试）：`npm run server`（3000）+ `npm run dev`（18888，/api 自动代理到 3000）。


## 功能地图

| 页面 | 干什么 |
| --- | --- |
| 总览 | 倒计时、三科预估分、今日任务、目标拆解、模考记录 |
| 冲刺计划 | 5 周逐日任务清单（82 项，可勾选、可打印/导出 PDF） |
| 课程学习 | 三科 46 讲零基础讲义（概念→例题→口诀→速记卡），可打印讲义 |
| 专项练习 | 按考点/难度/题型/真题筛选刷题，分层抽样保证覆盖面，即时判分解析，答错自动进错题本 |
| 模拟考试 | 按现行真实试卷结构组卷、150 分钟计时、答题卡、主观题自评、成绩单打印/导出 PDF |
| 错题本 | 自动收集错题，重做答对两次自动「毕业」，薄弱考点统计，支持打印/导出 PDF |
| 速记卡 | 全部课件要点翻卡自测（200+ 张，通勤碎片时间用） |
| 江苏考情 | 科目结构、时间线、分数线参考、加分政策、考场清单、官方渠道 |
| 抢分策略 | 三科零基础抢分路线、答题/蒙题技巧、考场时间分配 |
| 设置 | 姓名（打印页眉用）、考试日期修正、进度备份/清空 |

**打印 / 导出 PDF**：错题本、模考成绩单、讲义、计划表、考情页都支持——「打印」调起系统打印（可选另存为 PDF），「导出 PDF」直接下载 A4 多页 PDF（html2canvas + jsPDF）。

## 内容规模

| 科目 | 课件 | 题库 | 其中真题 |
| --- | --- | --- | --- |
| 政治 | 15 讲（马哲 7 + 毛中特中特 6 + 方法时政 2） | 149 题（选择 100 / 主观 47 + 辨析 2） | 2017、2018 卷 52 题 |
| 英语 | 13 讲（语音词汇 2 + 核心语法 7 + 题型技巧 4） | 248 题（含完形 4 篇、阅读 17 篇、对话 4 段、写作范文 3 篇） | 2019–2021 三年全卷 181 题 |
| 高数（一） | 18 讲（七大板块 + 抢分策略与公式手册） | 190 题（选择 101 / 填空 50 / 解答 39） | 2021–2025 五年卷 119 题 |
| **合计** | **46 讲** | **587 题** | **352 题** |

- 每道题都有「解析 + 零基础提示」，主观题带分步参考答案与评分要点；真题转化时逐题独立验算。
- 模拟考按现行题式组卷：政治 35 选择+4 简答+2 论述 = 41 题；英语 61 题六部分；高数 12 选择+3 填空+3 解答 = 18 题。

## 内容维护

- 数据结构见 `src/types.ts`；改完跑 `npm run typecheck` 与 `npm run test:data` 自检。
- 时事政治题（约 4~5 道选择）**需要考前 2 周人工更新**：看新华社年度国内/国际十大新闻 + 当年政府工作报告要点，替换政治题库中 `source: '时政示例'` 的题目（课件 pol-15 有方法）。
- 分数线、考试时间等以江苏省教育考试院（www.jseea.cn）当年公布为准，可在「江苏考情」页核对更新。

## 已知说明

- 在 ZCode 内置浏览器里控制台可能出现一条 `Cannot read properties of undefined (reading 'startTime')`（含 `reportAllChanges`）报错——经排查它来自内置浏览器自身的注入统计脚本（`reportAllChanges` 在本项目依赖与构建产物中均不存在），不影响任何功能；介意的话用系统浏览器（Chrome/Edge）打开同一地址即可。
- 政治 2021/2022 真题源仅存残卷，未收录；2019–2022 英语、2021–2025 高数真题完整。
- 高数 2021 卷源站缺第 5 题；政治 2017 卷缺 43~46 题答案，均未编造补齐。
- 模拟卷为题库智能组卷（结构对照真实试卷），题量不足的部分按实际题量组卷。
